# CRM for Electronics Repair

This project is a Customer Relationship Management (CRM) application for an electronics repair shop, built with a Django backend and a React frontend.

## Installation

To get the project up and running, you'll need to install the dependencies for both the backend and the frontend.

### Backend Dependencies

To install the Python packages required for the Django backend, run the following command in the root directory of the project:

```bash
pip install -r requirements.txt
```

### Frontend Dependencies

To install the Node.js packages required for the React frontend, navigate to the `frontend` directory and run the following command:

```bash
cd frontend
npm install
```

## Running the Application

### Backend

To run the Django development server, run the following command in the root directory of the project:

```bash
python manage.py runserver
```

### Frontend

To run the React development server, navigate to the `frontend` directory and run the following command:

```bash
cd frontend
npm start
```
